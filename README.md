# Biometrically Enabled RFID Card 

# About this Project

The projects goal is to create a security measure by using an RFID reader paired with Biometry.

# Requirements
Hardware:
- Pi5 (8gb) or similar 
- Pi Camera
- M5Stack Mini RFID Reader/Writer Unit

Software
- Debian 13 (Linux)
