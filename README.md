# Biometrically Enabled RFID Card

## Current Equipment:
- Pi4 4GB
- Pi3 2GB (x3)
- Pi3 1GB 
- Motion Sensor x6
- Pi Camera
- RFID Reader + 10 RFID Cards
- Ribon connectors x80

## Project Scope:
- Scan RFID
- Scan Biometrics
- Store Data
- Match Biometric to RFID 
- Bio Unlocks RFID
- LED Acceptance Signals (for testing)

## Possible Biomtric Sources:
- Face ID
- Finger Scanner
- Particular Testicular Detection (PTD)
